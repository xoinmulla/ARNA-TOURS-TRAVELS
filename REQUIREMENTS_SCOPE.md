# Arna Tours & Travels — Requirements Scope Update

This build removes the three admin modules explicitly identified as not being part of the Developer Requirements document:
- Website Content / CMS
- Business Settings
- System Health

The following requested backend capabilities are included:
- Booking system and admin booking workflow
- Customer management
- Vehicles, services, destinations, drivers and tour packages already present in the project
- Customer testimonials CRUD in the admin panel; only ACTIVE testimonials render on the homepage carousel
- Editable Tour Package navbar categories; seeded as Domestic, International and Dandeli
- Tour packages can be assigned to a category from the admin panel and public category links filter the packages
- Existing booking/security/route-recommendation foundations remain intact

The public contact page does not depend on the removed Business Settings module.
